# 營享-綠色露營共享平台

這是一個可直接用瀏覽器開啟的靜態 demo repo，將「營享-綠色露營共享平台」做成可操作的綠色露營用品共享與行程媒合原型。介面以戶外地圖、裝備庫存、押金清潔管理與出租者工作台為主，不是單純介紹頁。

## Demo 功能

- 營地與日期搜尋：依地區、人數、夜數和交通方式篩選可媒合營地。
- 裝備租借：可依類別瀏覽帳篷、炊事、睡眠、照明與能源裝備，加入或移出租借清單。
- 碳減量估算：依共享裝備、夜數、人數與交通方式估算減碳量。
- 押金與清潔狀態：即時計算租金、押金、保險與清潔提醒。
- 地主/出租者儀表板：模擬核准、清潔安排、保險補件等營運待辦。
- 行前檢查清單：可勾選露營前任務，進度會暫存在瀏覽器 localStorage。
- 評價與保險提示：顯示承租評價、保障提醒與可切換的安心保障方案。

## 使用方式

直接在瀏覽器開啟 `index.html` 即可使用。此 demo 使用純 HTML、CSS、JavaScript，沒有外部依賴，可部署在 GitHub Pages。

## 檔案

- `index.html`：主頁面與互動區塊。
- `styles.css`：響應式版面與視覺設計。
- `app.js`：搜尋、租借清單、估碳、清單與儀表板互動。
- `SOURCE.md`：來源資訊與資料使用說明。
- `README.md`：專案說明。

## 驗證

完成時使用：

```bash
node --check app.js
```
